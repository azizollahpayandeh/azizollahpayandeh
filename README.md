# Hi, I'm Azizollah Payandeh

**Network Administrator & Full-Stack Developer** at Sabanet, an ISP in Mashhad, Iran.

I spend my days on real networks (routers, switches, virtualization, VoIP) and my nights writing code for the web. Right now I'm moving deeper into offensive security. My goal is to work as a red teamer, so I'm studying security seriously and doing bug bounty on the side.

<br>

## What I work on

**Networks & infrastructure**
MikroTik RouterOS (VLANs, policy-based routing, multi-SSID, link aggregation, load balancing, failover), Cisco switching (trunk/access ports, STP, VTP, voice VLAN, management VLAN with Telnet/SSH), VMware ESXi 7 (installation, VM provisioning, RAID, iLO), and VoIP systems (trunks, IVR, extensions, paging, working-hours policies).

**Web development**
Front end with React, Next.js and TypeScript. Back end with Django, PostgreSQL and REST APIs. I like clean, simple interfaces that actually work on every screen.

**Security**
Currently taking CS50's Introduction to Cybersecurity from Harvard. Learning web application security, practicing on bug bounty platforms, and getting comfortable on Linux (my daily driver is Debian based).
